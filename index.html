How it works

The CSV is cleaned and transformed into date features plus numeric and rice-type inputs. Three regression pipelines are compared on a time-aware test split using MAE, RMSE, and R². The best pipeline is saved and loaded by Flask. The application then compares predicted demand with current stock to flag shortage or excess.

This educational demo uses a deterministic sample dataset. Replace data/rice_inventory.csv with historical mill records and rerun python train_model.py.
